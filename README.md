# student-bot
Телеграм бот створений для студентів, який допомагає не думати про зайві речі. Він самостійно шукає Ваш розклад, у випадку змін сповіщає Вас, слідкує за погодою протягом дня, радить що одягнути, та чи потрібна парасолька. Також є функція голосових нотаток, Ви записуєте голосове поміж парами, а бот структурує його, та створить завдання з дедлайном
